## Live reload helper

Use the local virtual environment and helper script to preview the site with automatic browser refresh.

1. Activate the virtual environment:
   ```bash
   source .venv/bin/activate
   ```
2. Run the live reload server:
   ```bash
   python live_reload.py
   ```
3. Open `http://127.0.0.1:8000` in the browser.

Edit `index.html`, `styles.css`, or `script.js` and the page will reload automatically.
